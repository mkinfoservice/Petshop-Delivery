# Roteiro: Acessar módulo Produtos

**Vídeo:** `01-acessar-produtos`
**Módulo:** Produtos
**Duração estimada:** ~30 segundos

---

## Objetivo

Mostrar como navegar do Dashboard ao módulo de Produtos.

---

## Cenas

### Cena 1 — Dashboard principal
- Tela: `/app`
- Legenda: *"Você está no Dashboard principal do vendApps. Aqui você tem uma visão geral do negócio."*
- Pausa: 2,5 s

### Cena 2 — Navegar para Produtos
- Legenda: *"Para acessar o catálogo de produtos, clique em Produtos no menu lateral."*
- Pausa: 1,5 s
- Ação: navega para `/app/produtos`

### Cena 3 — Lista de Produtos
- Legenda: *"Bem-vindo ao módulo de Produtos! Aqui você gerencia todo o catálogo da sua empresa."*
- Pausa: 3 s

---

## Observações

- Navegação direta por URL para garantir confiabilidade do vídeo.
- O menu lateral pode ter diferentes layouts — a navegação direta é preferida.
